Privacy Policy — Wonderquirk Office

Last updated: 7 November 2026

"Wonderquirk Office" is a private production tool used only by the creator of the YouTube channel WonderquirkTV. It is not offered to the public and has a single user: the channel's owner. This policy explains what the tool does with Google user data.

What the tool accesses

With the channel owner's consent (Google OAuth), the tool requests two read-only permissions:

  • YouTube Analytics (yt-analytics.readonly) — to read the channel's own statistics for its own videos (views, watch time, average view duration and percentage, subscribers gained, likes, comments, shares, and thumbnail impressions and click-through rate from the YouTube Reporting API).
  • YouTube account (youtube.readonly) — to confirm that the signed-in channel is the WonderquirkTV channel, and to look up public search results and public view counts when researching episode topics.

The tool cannot upload, edit, delete or publish anything, and it never accesses any other Google data.

How the data is used and stored

  • The numbers are stored only on the channel owner's own computer, in the tool's local records, to compare the channel's episodes with each other and decide what to make next.
  • The access token is stored locally on that computer and is never shared.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • The tool does not collect any data about viewers beyond the aggregated statistics YouTube Analytics provides to every channel owner.

Revoking access

Access can be removed at any time at myaccount.google.com/connections (Wonderquirk Office → Remove access). The locally stored data can be deleted by the owner at any time.

Google API Services User Data Policy

Wonderquirk Office's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
